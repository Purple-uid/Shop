# Nova Shop

Интернет-магазин на React + TypeScript.

**Деплой:** [shop-six-pied.vercel.app](https://shop-six-pied.vercel.app/)

## Технологии

- React 19 + TypeScript
- Vite 8
- React Router 7
- TanStack React Query
- Zustand (persist в localStorage)
- Axios
- React Icons (Feather)

## Функционал

- Каталог товаров с поиском по названию и категории
- Страница товара с рейтингом, ценой, описанием
- Корзина с изменением количества, суммой, sticky-блоком итого
- Авторизация / Регистрация (локальная, localStorage)
- Личный кабинет с информацией и статистикой корзины
- Приватные маршруты
- Адаптивная вёрстка
- Скелетоны загрузки
- Промо-баннер на главной

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Сборка

```bash
npm run build
```
