# Nova Shop

Интернет-магазин на React + TypeScript

## Технологии
- React 19
- TypeScript
- React Router
- useContext (авторизация)
- Fake Store API
- Zustand
- Axion/React-Query

## Функционал
- Каталог товаров с поиском по категории
- Страница товара с рейтингом
- Корзина
- Авторизация / Регистрация

## Установка зависимостей
npm install

## Запуск
npm run dev
